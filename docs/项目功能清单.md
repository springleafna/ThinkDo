# ThinkDo 项目功能清单

## 1. 项目简介

ThinkDo 是一个基于 Spring Boot 的多模块后端项目，聚焦于「AI 对话 + 知识库 + 笔记 + 计划管理」一体化场景，支持普通聊天、RAG 问答、任务管理与个人知识沉淀。

## 2. 功能总览

| 模块 | 功能清单 | 说明 |
| --- | --- | --- |
| 系统模块（`think-do-system`） | 用户注册、登录、登出、修改密码、查询个人信息 | 提供基础账号体系与鉴权能力（`/system/user`） |
| AI 对话模块（`think-do-ai`） | 流式聊天、停止生成、会话列表、历史消息、会话重命名、会话删除 | 支持 SSE 实时输出与会话管理（`/aiTest/chat`） |
| RAG 对话模块（`think-do-knowledge`） | RAG 流式问答、是否启用知识库检索、会话管理 | 在对话中融合知识库召回结果（`/ai/chat`） |
| 知识库模块（`think-do-knowledge`） | 知识库创建/重命名/删除/详情/分页 | 管理知识空间（`/knowledge-base`） |
| 文档管理模块（`think-do-knowledge`） | 文档上传、切块入库、启用/禁用、删除、更新、分页、搜索 | 支持文档解析、分块与向量化（`/knowledge-base/.../docs`） |
| 笔记模块（`think-do-note`） | 笔记增删改查、列表筛选、全文搜索、收藏切换、统计、最近笔记 | 覆盖日常记录与快速检索（`/note`） |
| 笔记分类模块（`think-do-note`） | 分类增删改查、分类列表 | 便于笔记归档（`/note/category`） |
| AI 笔记增强（`think-do-note`） | 润色、扩写、纠错、格式化（流式返回） | 基于 AI 的文本加工能力（`/note/ai/transform/stream`） |
| 计划模块（`think-do-plan`） | 计划增删改查、按分类查询、状态切换、AI 创建计划、四象限计划 | 覆盖待办与目标管理（`/plan/plan`） |
| 计划步骤模块（`think-do-plan`） | 步骤增删改查、按计划查询步骤、步骤状态切换 | 支持计划拆解执行（`/plan/step`） |
| 每日清单模块（`think-do-plan`） | 每日任务增删改查、按日期查询、查询今日清单、状态切换 | 连接计划与每日执行（`/plan/execution`） |
| 计划分类模块（`think-do-plan`） | 分类增删改查、分类列表 | 管理计划分组（`/plan/category`） |
| 便签模块（`think-do-plan`） | 便签增删改查、置顶切换、最新便签 | 轻量信息记录（`/plan/memo`） |

## 3. 关键技术能力

- 多模型路由与故障切换：支持首包检测、自动降级、熔断恢复，提升 AI 服务可用性。
- RAG 检索增强：支持向量检索与意图导向检索，多通道召回后再排序。
- 文档处理链路：支持文档上传、解析、分块、向量入库与检索。
- 向量数据库集成：集成 Milvus，支持知识检索与语义匹配。
- 统一鉴权与会话：基于 Sa-Token 的认证鉴权机制。
- 模块化架构：按 `system / ai / knowledge / note / plan` 拆分，便于独立演进。

## 4. 模块结构（后端）

- `think-do-common`：通用返回、异常、工具与基础配置
- `think-do-framework`：中间件与框架配置（如权限、数据库、Redis 等）
- `think-do-api`：模块间契约定义
- `think-do-system`：用户与系统能力
- `think-do-ai`：聊天、模型路由、流式输出
- `think-do-knowledge`：知识库、文档、RAG 检索
- `think-do-note`：笔记与 AI 文本增强
- `think-do-plan`：计划、步骤、每日清单、便签
- `think-do-start`：应用启动与环境配置

## 5. 适用场景

- 个人知识管理与智能问答
- 日常待办与目标执行追踪
- 笔记内容智能整理与优化
- 面向工作流的 AI 助手后端能力建设
